- `script.js` — mobile navigation menu

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `your-username.github.io` (replace `your-username` with your GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root folder.
3. Open **Settings → Pages** and select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)`, then save.
5. Wait a few minutes and visit `https://your-username.github.io`.

You can also name the repository something like `my-portfolio`; in that case, the Pages URL is usually `https://your-username.github.io/my-portfolio/`.
